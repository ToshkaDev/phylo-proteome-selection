# GTDB r232 genome selection

A compact workflow: **calculate patristic distances from the GTDB r232 Newick trees → derive family regions → select the 3,424-genome baseline → incorporate model organisms**.

## Run

Use Python 3.10+ from this directory:

```bash
python -m pip install -r requirements.txt
python run_pipeline.py
```

The scripts use paths relative to this folder; no manual path editing or working-directory setup is needed.

## What the workflow does

1. **Phylogenetic reconstruction (`scripts/reconstruct_phylogeny.py`)** — reads the supplied GTDB r232 bac120/ar53 Newick trees and metadata, maps eligible species labels to order/family, computes minimum leaf-to-leaf patristic distances for every family pair within each order, calculates each family’s nearest-family distance, sets the order cutoff to 1.75 × median nearest-family distance, and assigns family regions using complete-linkage clustering.
2. **Baseline (`scripts/select_baseline.py`)** — applies the CheckM2 threshold (completeness ≥80%, contamination ≤5%), preserves five documented legacy archaeal lineage-recovery exceptions, uses the previous selection only for per-order quotas, and selects families by reconstructed phylogenetic coverage. Output is exactly 3,424 unique accessions (3,182 Bacteria; 242 Archaea).
3. **Model organisms (`scripts/include_model_organisms.py`)** — starts from the baseline, prefers requested model genomes within already represented families, and uses coverage-aware family swaps where possible. Target conflicts and unresolved cases are recorded in an audit.
4. **Explicit taxonomy updates (`scripts/add_aliases_and_mk_d1.py`)** — adds the current GTDB r232 matches for _Borreliella burgdorferi_ B31, _Methanocaldococcus jannaschii_, _Saccharolobus solfataricus_, and _Prometheoarchaeum syntrophicum_ MK-D1. MK-D1 is an intentional quality exception (92.65% completeness; 6.22% contamination).

Five targets are intentionally omitted: _Caulobacter crescentus_, _Mycoplasma genitalium_, _Mycoplasma pneumoniae_, _Streptomyces coelicolor_, and _Candidatus Carsonella ruddii_.

## Files

- `inputs/` — GTDB r232 metadata, the previous selection (for order quotas/exceptions), original GTDB r232 bac120/ar53 Newick trees, and the reconstructed distance/region tables generated by stage 1.
- `scripts/` — the four sequential workflow stages.
- `inputs/phylogeny/` — output of `reconstruct_phylogeny.py`; regenerated automatically before baseline selection.
- `outputs/baseline/` — fixed-size 3,424-genome selection and its phylogenetic coverage audit.
- `outputs/model_enriched/` — model-aware selection, target audit, final selection, and explicit-additions audit.
- `validate.py` — checks core counts, unique accessions, explicit model accessions, ignored targets, and the MK-D1 exception.

## Verified counts

| Output                         | Genomes |
| ------------------------------ | ------: |
| Phylogenetic baseline          |   3,424 |
| Model-aware selection          |   3,438 |
| Final model-enriched selection |   3,442 |

The model-enriched output can exceed 3,424 because some model genomes are retained as additions when a safe phylogenetic replacement is unavailable. The baseline is a reproducible coverage-oriented reconstruction, not a claim to recover the exact historical algorithm. Five preserved legacy archaeal exception rows are outside the standard 80/5 quality filter.

The reconstruction script maps all 162,879 quality-filtered metadata rows to the included trees: all 155,439 eligible bacterial and 7,440 eligible archaeal species labels were found in the corresponding tree. It generated 66,566 family-pair distances across 772 multi-family orders, with complete family-pair coverage in all 772.
