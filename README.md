# PhyloProteomeSelection

Phylogeny-aware selection of taxonomically balanced organisms with broad evolutionary coverage and high-quality proteomes across prokaryotes and eukaryotes.

PhyloProteomeSelection is a reproducible computational pipeline for selecting representative organisms from prokaryotic and eukaryotic diversity. It combines phylogenetic distances, lineage-level sampling, genome-quality assessment, and proteome availability to maximize evolutionary coverage while maintaining a curated, high-quality set of proteomes for downstream comparative analyses.

The framework is designed to support large-scale protein family discovery, evolutionary analysis, functional annotation, and comparative studies across the tree of life.
